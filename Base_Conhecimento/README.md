#### Imersão Dev da Alura com Google Gemini (10ª Edição)</h2>
##### Esse projeto foi desenvolvido durante a Imersão Dev da Alura com Google Gemini (10ª Edição), onde utilizamos ferramentas como HTML, CSS e JavaScript para criar uma base de conhecimento. Com a ajuda do Gemini, populamos o JSON com diversas linguagens de programação e tecnologias, a fim de oferecer um guia de pesquisa rápido sobre todas elas, com título, ano de criação, resumo e direcionamento para a documentação oficial.

##### Confira mais detalhes sobre o que foi desenvolvido através desse [link](https://lauragrandoo.github.io/ProjetosCursos/Base_Conhecimento/).
