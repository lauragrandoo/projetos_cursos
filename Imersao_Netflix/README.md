#### Esse projeto foi desenvolvido durante a Imersão Front-End com IA da Alura, onde utilizamos ferramentas como HTML, CSS e JavaScript para reproduzir características da plataforma Netflix. 
#### Com isso, esse projeto conta com:

 - Tela de seleção de perfis;
 - Sessão de catálogo;
 - Layout responsivo;
 - Light/Dark mode;
 - Netflix Humor (exclusiva dessa imersão): recomendações de títulos com base no humor;
 - Trilha Sonora (exclusiva da imersão): onde o usuário pesquisa por um título e descobre todas as músicas relacionadas a ele.

#### Confira mais detalhes sobre o que foi desenvolvido através desse [link](https://lauragrandoo.github.io/ProjetosCursos/Imersao_Netflix/).
